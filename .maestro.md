## Code Conventions (JavaScript)

### API Fetch Patterns
Dilarang menggunakan `fetch` langsung di dalam komponen UI. Gunakan utility terstandarisasi:
- **`wpFetch(endpoint, options)`**: Wrapper untuk fetch dari WordPress core REST API (`/wp/v2/`).
- **`bwFetch(endpoint, options)`**: Wrapper untuk fetch dari custom endpoints (`/bw/v1/`).

### Naming Patterns
| Pattern | Example | Usage |
|---------|---------|-------|
| `get{Noun}BySlug` | `getServiceBySlug` | Single item fetch |
| `getAll{Nouns}` | `getAllServices` | List fetch |
| `formatDate` | `formatDate(dateString)` | Format date to `id-ID` locale |
