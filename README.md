# Bengkel Wiguna - Official Website (V3)

Selamat datang di repositori resmi pengembangan website **Bengkel Wiguna**. Proyek ini merupakan migrasi ke arsitektur modern berbasis Next.js untuk memberikan performa, SEO, dan pengalaman pengguna yang optimal.

## 🚀 Tech Stack

- **Framework**: [Next.js 15.5+](https://nextjs.org/) (App Router)
- **UI Library**: [NextUI](https://nextui.org/)
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion & AOS
- **Slider**: Splide.js
- **Icons**: Lucide React & Iconify

## 🛠️ Pengembangan Lokal

Pastikan Anda telah menginstal Node.js versi terbaru.

1. **Instalasi Dependensi**:
   ```bash
   npm install
   ```

2. **Menjalankan Server Development**:
   ```bash
   npm run dev
   ```
   Akses di [http://localhost:3000](http://localhost:3000).

3. **Build Produksi**:
   ```bash
   npm run build
   ```

## 📂 Struktur Folder

- `src/`: Berisi logika aplikasi, komponen, dan halaman.
- `public/`: Aset statis (gambar, ikon, logo).
- `_archived_files/`: Arsip file legacy dan dokumen pendukung (diabaikan oleh Git).

## 🌐 Deployment

Proyek ini dikonfigurasi untuk dideploy secara otomatis melalui **Vercel**. Pastikan environment variables (jika ada) sudah dikonfigurasi di dashboard Vercel.
