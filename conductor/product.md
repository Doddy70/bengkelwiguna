# Bengkel Wiguna V3

> Modern Headless CMS for Bengkel Wiguna (Automotive Service).

## Problem
Legacy Bootstrap-based site was difficult to maintain, lacked real-time backend synchronization, and had poor SEO/Performance metrics.

## Solution
A Next.js 15+ App Router application integrated with a custom WordPress plugin (BW Headless CMS) for high-performance, real-time content management and premium UI/UX.

## Core Features
| Feature | Status | Description |
|---|---|---|
| Dynamic Services | implemented | Managed via WP CPT |
| Real-time FAQ | implemented | Managed via WP Settings |
| Dynamic Navigation | in-progress | Controlled via WP Menus |
| One Stop Service Tabs | implemented | High-end UI component |
| ISR Revalidation | implemented | Near real-time updates |
