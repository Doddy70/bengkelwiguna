## Quick Answer

**Compression test** mengukur tekanan kompresi di setiap silinder untuk diagnose kesehatan mesin. Hasil normal: **125-180 PSI** (tergantung mesin). Hasil rendah di satu silinder = masalah di silinder tersebut. Hasil rendah merata = masalah keseluruhan (ring/piston).

> ⚠️ **Gunakan hasil compression test bersama teknisi** untuk diagnosis akurat.

---

## Apa Itu Compression Test?

### Definition

Compression test adalah prosedur diagnostik yang mengukur tekanan maksimum yang dihasilkan setiap silinder saat piston compresses udara-fuel mixture pada power stroke.

### Purpose

| Tujuan | Description |
|--------|-------------|
| **Cylinder Health** | Cek kondisi silinder secara umum |
| **Ring Condition** | Evaluasi kondisi ring piston |
| **Valve Sealing** | Cek valve seal |
| **Head Gasket** | Deteksi kebocoran head gasket |
| **Baseline** | Establish reference untuk future diagnosis |

### Preparation Steps

```
PERSIAPAN COMPRESSION TEST:
1. Pastikan mesin COLD (dingin)
2. Lepas semua spark plugs
3. Putar engine tanpa fuel (crank only)
4. Matikan ignition system
5. Hold throttle WIDE OPEN

```

## Cara Melakukan Compression Test

### Step-by-Step

```
COMPRESSION TEST PROCEDURE:
│
├── STEP 1: PERSIAPAN
│   ├── Pastikan mesin dingin
│   ├── Lepas semua spark plugs
│   └── Pastikan battery full
│
├── STEP 2: KONEKSI
│   ├── Screw compression tester ke cylinder #1
│   └── Pastikan tight seal
│
├── STEP 3: CRANK ENGINE
│   ├── Minta helper crank engine
│   ├── Hold throttle OPEN
│   ├── Catat tekanan puncak (peak pressure)
│   └── Tunggu sampai angka stabil
│
├── STEP 4: REPEAT
│   ├── Ulangi untuk setiap silinder
│   └── Catat semua hasil
│
└── STEP 5: WET TEST (optional)
    ├── Semprotkan sedikit oil ke silinder
    ├── Ulangi compression test
    └── Compare hasil dry vs wet
```

### Important Notes

```
⚠️ COMPRESSION TEST RULES:
├── Engine harus COLD (dingin)
├── Throttle harus WIDE OPEN
├── Disable ignition & fuel system
├── Crank minimum 6-8 compression strokes
├── Catat peak pressure (bukan reading terakhir)
└── Bandingkan antar silinder
```

## Reading & Interpretasi

### Normal Compression Range

| Engine Type | Normal PSI | Normal Bar |
|-------------|-----------|-----------|
| Most gasoline | 125-180 PSI | 8.6-12.4 Bar |
| High performance | 150-200 PSI | 10.3-13.8 Bar |
| Diesel | 300-500 PSI | 20.7-34.5 Bar |
| Low compression | 100-120 PSI | 6.9-8.3 Bar |

### What is Good Compression?

```
GOOD COMPRESSION CRITERIA:
├── Within 10-15% dari highest cylinder
├── Consistent antar silinder
├── Wet test improvement < 10%
└── Each cylinder > minimum spec
```

### Compression Pattern

| Pattern | Indikasi |
|---------|----------|
| All cylinders equal, good pressure | Engine healthy |
| One cylinder low | Localized problem |
| Two adjacent low | Head gasket atau head crack |
| Alternating pattern | Valve timing issue |
| All low | Ring/piston problem |

---

## Interpretasi Hasil

### Scenario 1: All Cylinders Equal but Low

```
HASIL: Semua silinder ~sama, tekanan rendah

PENYEBAB:
├── Ring piston aus
├── Piston worn/damaged
├── Cylinder walls worn
└── Valve timing problem

SOLUSI:
└─ Full overhaul atau ring replacement
```

### Scenario 2: One Cylinder Low

```
HASIL: Satu silinder rendah, lainnya normal

PENYEBAB:
├── Burned valve
├── Valve seat damage
├── Head gasket bocor
├── Piston/ring damage
└── Cracked head/block

DIAGNOSIS LANJUTAN:
└─ Perform leak down test untuk konfirmasi
```

### Scenario 3: Two Adjacent Cylinders Low

```
HASIL: Dua silinder bersebelahan rendah

PENYEBAB:
├── Head gasket bocor
├── Head crack antara silinder
└── Cooling jacket leak

DIAGNOSIS LANJUTAN:
└─ Check coolant untuk oil contamination
```

### Scenario 4: Dry vs Wet Test

```
DRY TEST (tanpa oil):
├── Baca compression normal

WET TEST (dengan oil):
├── Oil dispray ke silinder
├── Oil membantu seal ring temporarily

HASIL PERBANDINGAN:
├── Improvement > 15% → Ring/Piston problem
├── No improvement → Valve atau head gasket problem
└─ Both low → Localized problem (valve/head gasket)
```

## Compression vs Leak Down Test

### Comparison

| Aspek | Compression Test | Leak Down Test |
|-------|-----------------|----------------|
| **Mengukur** | Tekanan maksimum | Kehilangan tekanan |
| **Unit** | PSI / Bar | Persen (%) |
| **Kekurangan** | Tidak identifikasi WHERE leak | Tidak give absolute value |
| **Kelebihan** | Quick, screening tool | Precise location |
| **Best for** | Initial check | Follow-up diagnosis |

### When to Use Each

```
GUNAKAN COMPRESSION TEST UNTUK:
├── Quick health check
├── Screening sebelum overhaul
├── Buying used car inspection
└── Baseline comparison

GUNAKAN LEAK DOWN TEST UNTUK:
├── Locate exact leak source
├── Konfirmasi diagnosis
├── Pre rebuild inspection
└─ Kompleks diagnosis
```

## Common Mistakes

### Errors to Avoid

```
❌ SALAH:
├── Test dengan mesin panas → Reading tidak akurat
├── Throttle tidak open → Pressure artificially high
├── Battery lemah → Crank speed tidak cukup
├── Hanya test 1-2 silinder → Miss masalah
├── Tidak catat pattern → Sulit diagnosis
└─ Skip wet test → Miss ring diagnosis
```

## FAQ

### Apa itu compression test?

Compression test mengukur tekanan kompresi di setiap silinder untuk mengevaluasi kesehatan mesin. Reading normal 125-180 PSI untuk mesin bensin.

### Kapan perlu compression test?

Perlu saat mesin sulit start, kehilangan tenaga, makan oli, asap tidak normal, atau saat beli mobil bekas.

### Hasil bagus berapa PSI?

Mesin bensin normal: 125-180 PSI. Semua silinder harus dalam 10-15% dari nilai tertinggi.

### Berbeda dari leak down test?

Ya. Compression test = screening, mengukur tekanan total. Leak down test = diagnosis, mengidentifikasi LETAK kebocoran.

### Bisa dilakukan sendiri?

Bisa dengan compression tester. Tapi interpretasi dan diagnosis lanjutan sebaiknya oleh teknisi berpengalaman.
