## Quick Answer

**Head gasket bocor** adalah seal antara cylinder head dan block mesin yang gagal membuat seal sempurna. Gejala: mesin overheat, oli berbusa, asap putih dari knalpot, power loss. Solusi: **Ganti head gasket** dengan overhaul head. Biaya: **Rp 5.000.000 - Rp 25.000.000+**.

> ⚠️ **Diagnosis langsung dari teknisi tetap diperlukan** untuk konfirmasi head gasket bocor.

## Apa Itu Head Gasket?

### Definition

Head gasket (seal kepala silinder) adalah seal metal-composite yang dipasang antara cylinder head dan engine block. Fungsi: membuat seal combustion chamber, coolant passages, dan oil passages.

### Location

```
ENGINE BLOCK - TOP VIEW:
┌─────────────────────────────────────┐
│                                     │
│         CYLINDER HEAD               │
│    ┌─────────────────────┐        │
│    │   COMBUSTION        │        │
│    │     CHAMBERS         │        │
│    │   (x2, x4, atau x6) │        │
│    └─────────────────────┘        │
│              ↑                     │
│    ┌─────────────────────┐        │
│    │   HEAD GASKET       │ ← INI BOCOR │
│    ├─────────────────────┤        │
│    │   ENGINE BLOCK      │        │
│    │   (Cylinder bores) │        │
│    └─────────────────────┘        │
│                                     │
└─────────────────────────────────────┘
```

### Function

| Function | Description |
|----------|-------------|
| **Combustion Seal** | Seal combustion chamber dari coolant/oil passages |
| **Coolant Sealing** | Mencegah coolant bocor ke oil/ combustion |
| **Oil Sealing** | Mencegah oli masuk cooling system |
| **Compression** | Maintain compression ratio |

## Gejala Head Gasket Bocor

### Primary Symptoms

| # | Gejala | Severity | Notes |
|---|--------|----------|-------|
| 1 | **Mesin overheat kronis** | CRITICAL | Head gasket gagal seal pendingin |
| 2 | **Oli berubah jadi putih/kream** | CRITICAL | Coolant masuk oil pan |
| 3 | **Asap putih dari knalpot** | HIGH | Coolant terbakar di combustion |
| 4 | **Coolant hilang tanpa kebocoran** | HIGH | Coolant masuk mesin |
| 5 | **Power loss** | HIGH | Compression loss |
| 6 | **White milky residue di oil cap** | MEDIUM | Emulsifikasi oli |

### Secondary Symptoms

| Gejala | Penyebab |
|--------|----------|
| Coolant level turun terus | Kebocoran internal |
| Bubbles di radiator saat gas | Combustion gas masuk cooling |
| Sweet smell dari exhaust | Coolant terbakar |
| Rough idle | Compression tidak равномерный |
| Engine knocking | Head warping |

## Cara Diagnosis

### 1. Visual Inspection

```
CEK KONDISI MESIN:
├── Oil cap: ada white sludge/emulsion?
├── Oil dipstick: terlihat kream/berubah warna?
├── Coolant: berubah warna (minyak di coolant)?
├── Radiator cap: ada white foam saat dibuka?
└── Exhaust: asap putih terus meskipun mesin hangat?
```

### 2. Cooling System Test

| Test | Result | Interpretation |
|------|---------|----------------|
| **Block tester (combustion leak test)** | Blue fluid turns yellow | Exhaust gas entering cooling |
| **Radiator pressure test** | Pressure drops | External leak |
| **Coolant level check** | Turun tanpa kebocoran external | Internal leak |

### 3. Chemical Test

```
COOLING SYSTEM PRESSURE TEST:
1. Panaskan mesin ke operating temp
2. Matikan mesin, biarkan dingin
3. Buka radiator cap
4. Pasang pressure tester
5. Pump sampai 15 psi
6. Amati pressure gauge:

Pressure STABIL → Sealing OK
Pressure DROP → Kebocoran (external atau internal)
Ada gelembung dari coolant → Head gasket bocor
```

### 4. Compression & Leak Down Test

| Test | Result | Interpretation |
|------|---------|----------------|
| **Compression test** | Low pada 1 silinder | Head gasket atau valve issue |
| **Leak down test** | Leak ke cooling system | Head gasket bocor |
| **Wet compression** | No improvement | Bukan ring, kemungkinan head gasket |

## Penyebab Head Gasket Bocor

### Primary Causes

| Penyebab | Notes |
|----------|-------|
| **Overheating** | Penyebab #1 - head warping |
| **Age/wear** | Head gasket kehilangan elasticity |
| **Improper torquing** | Head bolt tidak равномерный saat assembly |
| **Head warping** | Dari overheat berulang |
| **Corrosion** | Electrolysis di cooling system |
| **Low coolant level** | Air pockets causing hot spots |
| **Wrong head gasket** | Aftermarket yang tidak sesuai spec |

### Risk Factors

| Faktor | Impact |
|--------|--------|
| Sering overheat | CRITICAL |
| Tidak pernah flush coolant | HIGH |
| Using wrong coolant | HIGH |
| Age >10 years | MEDIUM |
| Previous overheating incident | HIGH |

## Solusi & Perbaikan

### Head Gasket Replacement

**Proses:**
1. Drain coolant
2. Remove cylinder head
3. Inspect head for warping/cracking
4. Machine head surface (if needed)
5. Replace head gasket
6. Replace head bolts (torque to spec)
7. Reassemble with new gaskets

**Scope:** Head Overhaul
**Duration:** 3-7 hari kerja

### When Head Resurfacing Needed

```
PILIH HEAD RESURFACING JIKA:
├── Head surface warpage > 0.05mm
├── Visible cracks pada head
├── Blown head gasket berulang
└── History overheat severe
```

### When Full Engine Overhaul Needed

```
PILIH FULL OVERHAUL JIKA:
├── Head cracked (not just warped)
├── Block surface damaged
├── Multiple symptoms (compression loss + coolant loss)
└── Engine age > 200.000 km
```

## FAQ

### Apa itu head gasket?

Head gasket adalah seal metal-composite antara cylinder head dan engine block. Fungsinya: seal combustion chamber, coolant passages, dan oil passages.

### Gejala head gasket bocor?

Gejala head gasket bocor: mesin overheat, oli berubah warna (putih/kream), asap putih dari knalpot, coolant hilang tanpa kebocoran external.

### Berbeda dari overheat biasa?

Ya. Head gasket bocor = coolant hilang + oli berubah warna. Overheat biasa = hanya temperature naik, tidak ada mixing fluids.

### Berapa biaya perbaikan head gasket?

Biaya ganti head gasket: **Rp 5.000.000 - Rp 25.000.000+** tergantung severity dan tipe kendaraan.

### Bisa dicegah?

Ya. Rutin check coolant, jangan overheat, flush coolant sesuai schedule bisa mencegah head gasket bocor.
