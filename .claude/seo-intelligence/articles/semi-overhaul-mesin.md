## 1. Apa Itu Semi Overhaul?

Semi overhaul adalah proses perbaikan mesin yang lebih terbatas dari overhaul penuh. Berbeda dengan overhaul lengkap yang membongkar seluruh mesin, semi overhaul fokus pada komponen upper engine.

**Scope Semi Overhaul:**

| Termasuk | Tidak Termasuk |
|----------|----------------|
| Cylinder Head | Piston |
| Valve Stem Seal | Ring Piston |
| Head Gasket | Connecting Rod |
| Timing Belt/Chain | Crankshaft |
| Upper Gasket Set | Oil Pump Internal |
| Valve Job (jika perlu) | Cylinder Bore |

**Karakteristik Semi Overhaul:**

- **Duration:** 3-5 hari kerja
- **Cost:** Rp 3-10 juta
- **Scope:** Upper engine only
- **Warranty:** 3-6 bulan
- **Cocok untuk:** Valve seal bocor, head gasket early stage

### Kapan Semi Overhaul Cukup?

```
MESIN MAKAN OLI → ?
│
├── [ ] Apakah oli turun lebih cepat saat IDLE?
│   ├── YA → Kemungkinan Valve Seal Bocor
│   │         → Semi Overhaul CUKUP
│   │
│   └── TIDAK → Apakaholi turun saat GAS?
│               ├── YA → Kemungkinan Ring Piston
│               │      → OVERHAUL PENUH diperlukan
│               │
│               └── TIDAK → PCV Valve bermasalah
│                           → Service biasa cukup
```

> ⚠️ **Catatan Penting:** Decision tree di atas adalah panduan umum. Diagnosis langsung dari teknisi tetap diperlukan untuk konfirmasi.

## 2. Kapan Perlu Semi Overhaul?

### 5 Kondisi yang Memerlukan Semi Overhaul

| # | Kondisi | Gejala | Komponen |
|---|---------|--------|----------|
| 1 | **Valve Seal Bocor** | Mesin makan oli (parah saat idle), asap biru saat start dingin | Valve stem seal |
| 2 | **Head Gasket Bermasalah** | Overheat ringan, coolant kadang turun | Head gasket |
| 3 | **Timing Belt/Chain Aus** | Bunyi, timing slip, >60rb km | Timing belt kit |
| 4 | **Valve Aus/Bending** | Power drop, misfire ringan | Valve job |
| 5 | **Head Gasket Early Stage** | Kompresi turun di satu silinder | Head gasket |

### Gejala Utama: Mesin Makan Oli

**Valve Seal Bocor vs Ring Piston Aus:**

| Faktor | Valve Seal Bocor | Ring Piston Aus |
|--------|------------------|-----------------|
| **Kapan oli turun?** | Lebih parah saat IDLE | Konsisten saat jalan |
| **Asap biru** | Saat start dingin | Konsisten |
| **Oil pressure** | Normal | Bisa turun |
| **Oli di spark plug** | Ada | Tidak ada |
| **Compression test** | Normal | Low |

### Gejala Utama: Overheat

```
OVERHEAT BERULANG → ?
│
├── [ ] Apakah pernah OVERHEAT BERAT?
│   ├── YA → Apakah coolant bercampur OLI?
│   │         ├── YA → Head Gasket + Kemungkinan Block
│   │         │      → OVERHAUL PENUH
│   │         │
│   │         └── TIDAK → Head Gasket saja
│   │                    → Semi Overhaul
│   │
│   └── TIDAK → Apakah coolant turun TANPA rembesan?
│               ├── YA → Head Gasket early stage
│               │      → Semi Overhaul
│               │
│               └── TIDAK → Thermostat / Water Pump
│                           → Service cooling system
```

> ⚠️ **Catatan Penting:** Jika overheal BERAT dengan coolant bercampur oli, kemungkinan ada kerusakan di block. **Overhaul penuh mungkin diperlukan.**

## 3. Gejala yang Bisa Diatasi Semi Overhaul

### Table: Gejala → Solusi

| Gejala | Kemungkinan Penyebab | Tindakan |
|--------|---------------------|----------|
| Mesin makan oli ringan | Valve seal aus | Replace valve seal |
| Asap biru saat start | Valve seal bocor | Replace valve seal |
| Overheat ringan | Head gasket early | Replace head gasket |
| Power drop | Timing slip/belt melar | Replace timing belt |
| Bunyi kasar atas mesin | Timing chain aus | Replace timing chain |

### Gejala yang TIDAK Bisa Diatasi Semi Overhaul

| Gejala | Penyebab | Solusi |
|--------|----------|--------|
| Mesin makan oli parah | Ring piston aus | Overhaul Penuh |
| Compression loss semua cylinder | Bore aus | Overhaul Penuh |
| Bunyi ketuk bearing | Crankshaft/rod bearing | Overhaul Penuh |
| Vibrasi mesin | Crankshaft aus | Overhaul Penuh |

> ⚠️ **Catatan Penting:** Jika mesin mengalami gejala di kolom kiri, semi overhaul tidak akan menyelesaikan masalah. **Diagnosis tetap diperlukan.**

## 5. Proses Semi Overhaul Step-by-Step

### Timeline: 3-5 Hari Kerja

| Hari | Tahap | Aktivitas |
|------|-------|-----------|
| 1 | Persiapan | Drain coolant, disconnect battery |
| 2 | Remove | Lepas manifold, timing cover, cylinder head |
| 3 | Repair | Valve job, gasket replacement |
| 4 | Assembly | Pasang head, set timing |
| 5 | Testing | Start engine, check leaks |

### Detail Proses

**TAHAP 1: Persiapan**

```
1. Parkir di area kerja yang aman
2. Dinginkan mesin (min 30 menit setelah mati)
3. Disconnect battery (- terminal first)
4. Drain coolant ke container bersih
5. Dokumentasi: Foto posisi komponen
```

**TAHAP 2: Remove Upper Components**

```
1. Lepas intake manifold
   ├── Disconnect all sensors
   ├── Lepas bolts (spec torque)
   └── Angkat manifold dengan hati-hati

2. Lepas exhaust manifold
   ├── Lepas exhaust pipe connection
   └── Angkat manifold

3. Lepas timing cover
   ├── Dokumentasi timing marks
   └── Ambil foto posisi belt/chain

4. Lepas cylinder head
   ├── Lepas camshaft
   ├── Lepas valve train
   ├── Lepas head bolts (spec pattern)
   └── Angkat cylinder head
```

**TAHAP 3: Inspection & Repair**

```
HEAD INSPECTION:
├── Check flatness (max 0.10mm warpage)
├── Check untuk crack
├── Check valve seats
└── Check valve guides

VALVE JOB (jika perlu):
├── Grind valve seats
├── Check valve stem alignment
├── Replace valve stem seals (WAJIB)
└── Lap valves

HEAD GASKET REPLACEMENT:
├── Clean head and block surface
├── Check surface flatness
├── Install new head gasket
└── Torque head bolts (spec: manufacturer)
```

**TAHAP 4: Assembly**

```
1. Install head gasket baru (arah排气)
2. Pasang cylinder head
3. Torque head bolts (spec sequence)
4. Install valve train
5. Set timing (belt/chain)
6. Install exhaust manifold
7. Install intake manifold
8. Fill coolant
```

**TAHAP 5: Testing**

```
START ENGINE:
├── Check oil pressure (25-65 PSI)
├── Check coolant level
├── Start engine (perhatikan bunyi)
└── Monitor temperature gauge

LEAK CHECK:
├── Periksa kebocoran coolant
├── Periksa kebocoran oli
├── Periksa kebocoran gas
└── Road test (10-15 menit)
```

## 7. Perbandingan: Semi Overhaul vs Overhaul

### Comparison Table

| Kriteria | Semi Overhaul | Overhaul Penuh |
|----------|---------------|----------------|
| **Scope** | Upper engine | Full engine |
| **Duration** | 3-5 hari | 7-14 hari |
| **Cost** | Rp 3-10 juta | Rp 8-30 juta |
| **Components** | Head, valve, gasket | Semua komponen |
| **Cocok untuk** | Valve seal, head gasket | Ring aus, bore macet |
| **Garansi** | 3-6 bulan | 6-12 bulan |
| **Recovery** | Faster | Longer |

### When to Choose Semi Overhaul

```
CHOOSE SEMI OVERHAUL IF:
├── [ ] Mesin makan oli ringan-sedang
├── [ ] Overheat ringan tanpa coolant campur oli
├── [ ] Timing belt/chain perlu ganti
├── [ ] Budget terbatas
├── [ ] Teknisi merekomendasikan
└── [ ] Compression test: OK on most cylinders

⚠️ JANGAN pilih semi overhaul jika:
├── Mesin makan oli parah (>1L/1000km)
├── Compression loss signifikan
├── Bore aus
└── Teknisi merekomendasikan overhaul
```

### Decision Guide

| Kondisi | Rekomendasi |
|---------|------------|
| Mesin makan oli ringan + compression OK | Semi Overhaul ✅ |
| Head gasket early + no oil mixing | Semi Overhaul ✅ |
| Timing belt >60rb km | Semi Overhaul ✅ |
| Mesin makan oli parah + compression loss | Overhaul Penuh ❌ |
| Coolant campur oli (berat) | Overhaul Penuh ❌ |
| Bore aus/scoring | Overhaul Penuh ❌ |

## 9. FAQ

### Apa bedanya semi overhaul dengan overhaul penuh?

Semi overhaul fokus pada komponen upper engine (cylinder head, valve, head gasket) tanpa membongkar block mesin. Overhaul penuh membongkar seluruh mesin termasuk piston, ring, dan crankshaft.

### Berapa lama semi overhaul mesin?

Semi overhaul mesin membutuhkan waktu sekitar **3-5 hari kerja**, lebih cepat dari overhaul penuh yang membutuhkan 7-14 hari.

### Berapa biaya semi overhaul mesin 2026?

Biaya semi overhaul mulai dari **Rp 3.000.000 hingga Rp 10.000.000** tergantung tipe kendaraan dan komponen yang perlu diganti.

### Kapan semi overhaul sudah cukup?

Semi overhaul sudah cukup ketika masalah ada di komponen upper engine seperti valve seal bocor, head gasket bermasalah, atau timing belt aus.

### Apakah semi overhaul menyelesaikan mesin makan oli?

Semi overhaul bisa menyelesaikan mesin makan oli jika penyebabnya adalah valve seal atau head gasket. Jika penyebabnya adalah ring piston aus, semi overhaul tidak akan efektif.

### Hasil semi overhaul permanen?

Hasil semi overhaul bisa bertahan bertahun-tahun jika komponen yang diganti berkualitas dan penyebab masalah sudah terdiagnosis dengan benar. Garansi 3-6 bulan biasanya diberikan untuk labor.

### Apakah perlu turun mesin untuk semi overhaul?

Bergantung pada kendaraan. Beberapa mobil memerlukan turun mesin untuk akses cylinder head, sementara yang lain bisa dilakukan dengan mesin masih terpasang.
