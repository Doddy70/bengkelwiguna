## 1. Apa Itu Overhaul Mesin?

Overhaul mesin adalah proses pembongkaran total mesin mobil untuk memeriksa, memperbaiki, atau mengganti komponen internal yang aus atau rusak. Berbeda dengan service biasa (ganti oli, tune-up), overhaul melibatkan pembongkaran mesin secara menyeluruh.

**Scope Overhaul Lengkap:**

| Kategori | Komponen |
|----------|----------|
| **Upper Engine** | Cylinder Head, Valve, Valve Seal, Head Gasket, Timing Chain/Belt |
| **Lower Engine** | Piston, Ring Piston, Connecting Rod, Crankshaft, Oil Pump |
| **Block** | Cylinder Bore, Main Bearings, Caps |

**Tujuan Overhaul:**

- Mengembalikan performa mesin seperti kondisi baru
- Memperbaiki kompresi mesin yang hilang
- Mengatasi masalah mesin makan oli kronis
- Memperbaiki overheat berulang akibat head gasket

**Referensi:**
- Standar toleransi bore mesin: API Engine Service Guidelines
- Spec compression ratio: Toyota Service Manual (1NR-FE: 11.5:1, 2KD-FTV: 17.4:1)

## 2. Kapan Mesin Perlu Overhaul?

Menentukan kapan mesin butuh overhaul memerlukan diagnosis yang tepat. Gunakan flowchart di bawah sebagai panduan awal.

### Decision Tree: Kapan Perlu Overhaul?

```
MESIN MENGALAMI GEJALA?
│
├── MESIN MAKAN OLI?
│   │
│   ├── [ ] Apakah oli turun cepat SAAT IDLE?
│   │   ├── YA → Kemungkinan Valve Seal Bocor
│   │   │         → Test: Compression test + oil in plug well
│   │   │         → Rekomendasi: Semi Overhaul
│   │   │
│   │   └── TIDAK → Apakah oli turun konsisten SAAT JALAN?
│   │               ├── YA → Kemungkinan Ring Piston Aus
│   │               │         → Test: Compression test (dry + wet)
│   │               │         → Rekomendasi: Overhaul
│   │               │
│   │               └── TIDAK → PCV Valve bermasalah
│   │                           → Service biasa
│   │
├── TENAGA TURUN?
│   │
│   ├── [ ] Apakah ada BUNYI KETUK?
│   │   ├── YA → Kemungkinan:
│   │   │         ├── Connecting Rod Bearing aus
│   │   │         ├── Main Bearing aus
│   │   │         └── Piston macet
│   │   │         → Test: Oil pressure + stethoscope
│   │   │         → Rekomendasi: Overhaul
│   │   │
│   │   └── TIDAK → Kemungkinan:
│   │               ├── Timing Chain slip
│   │               ├── Fuel system issue
│   │               └── Compression loss
│   │               → Test: Compression test → Leak Down test
│   │
├── OVERHEAT BERULANG?
│   │
│   ├── [ ] Apakah COOLANT turun tanpa rembesan?
│   │   ├── YA → Kemungkinan Head Gasket bocor
│   │   │         → Test: Compression + leak down + coolant test
│   │   │         → Rekomendasi: Semi Overhaul / Overhaul
│   │   │
│   │   └── TIDAK → Kemungkinan:
│   │               ├── Thermostat rusak
│   │               ├── Water Pump aus

│   │               → Service cooling system
│   │
└── ASAP TIDAK WARAN?
    │
    ├── ASAP BIRU → Oli terbakar di ruang bakar
    │             → Penyebab: Valve Seal / Ring Piston
    │
    ├── ASAP PUTIH → Coolant terbakar
    │              → Penyebab: Head Gasket / Cylinder Head crack
    │
    └── ASAP HITAM → Campuran bahan bakar terlalu kaya

| **Timing Belt** | Sinkronisasi camshaft | Aus, retak, >60rb km | Visual inspection |
| **Piston** | Kompresi | Aus, rusak, scoring | Visual + measurements |

## 5. Proses Overhaul Step-by-Step

### Timeline: 7-14 Hari Kerja

| Hari | Tahap | Aktivitas |
|------|-------|-----------|
| 1 | Persiapan & Turun Mesin | Drain fluida, lepas komponen, turunkan mesin |
| 2-3 | Full Teardown | Bongkar cylinder head, oil pan, piston, crankshaft |
| 4 | Inspection & Measurement | Ukur bore, clearance, wear assessment |
| 5-6 | Component Repair | Bore/hone, valve job, grinding |
| 7-9 | Assembly | Pasang piston, head, timing, accessories |
| 10 | Engine Installation | Pasang mesin, sambung sistem, isi fluida |
| 11-12 | Tuning & Testing | Start engine, check oil pressure, road test |
| 13-14 | Quality Control | Final inspection, delivery preparation |

### Detail Proses

**1. Persiapan & Turun Mesin**

Persiapan yang matang menentukan kelancaran overhaul:

```
TAHAP 1.1: Drain Fluida
├── Engine oil drain
├── Coolant drain
├── Transmission fluid (jika diperlukan)
└── Dokumentasi: Foto/video kondisi awal

TAHAP 1.2: Remove External Components
├── Intake manifold
├── Exhaust manifold
├── Radiator + hoses
├── AC compressor
├── Alternator
├── Power steering pump
└── All electrical connectors

TAHAP 1.3: Engine Removal
├── Support engine dengan engine hoist
├── Lepas engine mounts (front, rear, side)
├── Lepas transmission connection
└── Angkat engine dari chassis
```

**2. Full Teardown**

```
TAHAP 2.1: Cylinder Head Removal
├── Lepas camshaft
├── Lepas valve train
├── Bongkar cylinder head
└── Inspect head untuk crack/warpage

TAHAP 2.2: Bottom End
├── Lepas oil pan
├── Lepas piston + connecting rod assemblies
├── Inspect crankshaft
└── Check main bearings
```

**3. Inspection & Measurement**

| Komponen | Alat Ukur | Standard | Limit |
|----------|-----------|---------|-------|
| Cylinder Bore | Bore gauge | API Std | Max taper 0.05mm |
| Ring End Gap | Feeler gauge | 0.25-0.40mm (new) | Max 1.0mm |
| Crankshaft Runout | Dial indicator | <0.05mm | <0.10mm |
| Main Bearing Clearance | Plastigage | 0.02-0.05mm | <0.10mm |
| Cylinder Head Flatness | Straight edge | <0.05mm | <0.10mm |

**4. Component Repair**

```
BORE/HONE
├── honing cylinder walls
├── Bore oversize jika perlu (+0.25mm, +0.50mm)
└── Final surface finish: 20-40 Ra

VALVE JOB
├── Grind valve seats
├── Replace valve stem seals
├── Check valve alignment
└── Lap valves

CRANKSHAFT
├── Grind journals jika aus
├── Replace main bearings
├── Check rod bearings
└── Polish journals
```

**5. Assembly**

```
UPPER ENGINE
├── Install new head gasket
├── Set valve train
├── Install camshaft + timing
└── Torque head bolts (spec: [Engine specific])

LOWER ENGINE
├── Install piston assemblies
├── Torque rod bolts (spec: [Engine specific])
├── Install oil pump
├── Install crankshaft caps
└── Check end play

FINAL ASSEMBLY
├── Install timing chain/belt
├── Set timing marks
├── Install accessories
└── Torque semua fasteners
```

**6. Engine Installation**

```
├── Pasang engine ke chassis
├── Kencangkan engine mounts
├── Sambung wiring harness
├── Pasang coolant hoses
├── Sambung fuel lines
└── Isi fluida (oli, coolant, transmission)
```

**7. Tuning & Testing**

| Test | Target | Pass Criteria |
|------|--------|---------------|
| Oil Pressure | 25-65 PSI | Within spec range |
| Compression | 125-180 PSI | No cylinder variation >10% |
| Coolant Temp | 85-95°C | Stable, no overheat |
| Idle Speed | 650-750 RPM | Stable |
| Road Test | No abnormal sounds | Power restored |

```
PILIH OVERHAUL LENGKAP JIKA:
├── [ ] Mesin makan oli >1L/1000km (kronis)
├── [ ] Compression loss di SEMUA cylinder

├── [ ] Budget terbatas
└── [ ] Teknisi merekomendasikan semi overhaul

## 8. Tes Diagnostik Sebelum Overhaul

Diagnosis yang tepat menentukan apakah perlu overhaul atau service biasa.

### Diagnostic Test Overview

| Test | Fungsi | Hasil Normal | Alat |
|------|--------|--------------|------|
| **Compression Test** | Ukur tekanan kompresi | 125-180 PSI | Compression tester |
| **Leak Down Test** | Deteksi kebocoran | <10% leakage | Leak down tester |
| **Oil Pressure Test** | Tekanan oli | 25-65 PSI | Oil pressure gauge |
| **Endoscope Inspection** | Visual bore condition | No scoring | Borescope |

### Compression Test Procedure

```
ALAT: Compression tester kit

LANGKAH:
1. Warm up engine ke operating temperature
2. Lepas semua spark plugs
3. Matikan ignition + fuel pump
4. Pasang compression tester
5. Crank engine 4-5 revolutions
6. Catat reading untuk setiap cylinder
7. Ulangi untuk semua cylinders

INTERPRETASI:
├── Semua cylinder 125-180 PSI → Engine OK
├── Variation >10% antar cylinder → Problem
├── Satu cylinder rendah → Local issue
└── Semua cylinder rendah → General wear
```

### Leak Down Test Procedure

```
ALAT: Leak down tester + air compressor

LANGKAH:
1. Lepas semua spark plugs
2. Set piston di TDC (compression stroke)
3. Pasang adapter ke spark plug hole
4. Hubungkan ke leak down tester
5. Beri tekanan 100 PSI
6. Dengarkan + amati kebocoran

HASIL:
├── 0-5% leakage → Excellent
├── 5-10% leakage → Acceptable
├── 10-20% leakage → Warning (inspection needed)
├── 20-30% leakage → Problem (repair needed)
└── 30%+ leakage → Critical (immediate repair)

LOKASI KEBOKORAN:
├── Intake manifold → Intake valve leak
├── Exhaust → Exhaust valve leak
├── Radiator/coolant → Head gasket
└── Crankcase → Ring/piston damage
```

## 10. FAQ: Pertanyaan Umum

### Berapa lama overhaul mesin mobil?

Overhaul mesin mobil membutuhkan waktu **7-14 hari kerja** tergantung tipe kendaraan dan kondisi mesin. Proses termasuk turun mesin, teardown, repair, assembly, dan testing.

### Apa bedanya overhaul dengan semi overhaul?

Overhaul adalah pembongkaran total mesin termasuk lower engine (piston, ring, crankshaft). Semi overhaul fokus pada upper engine (cylinder head, valve, head gasket) tanpa membongkar block.

### Berapa biaya overhaul mesin mobil 2026?

Biaya overhaul mesin mobil mulai dari **Rp 8.000.000 hingga Rp 30.000.000+** tergantung tipe kendaraan (city car vs SUV diesel).

### Kapan mesin perlu overhaul?

Mesin perlu overhaul ketika mengalami: mesin makan oli >1L/1000km, tenaga turun drastis, overheat berulang, atau bunyi ketuk yang tidak normal.

### Apakah overhaul mesin bisa klaim asuransi?

Umumnya overhaul mesin tidak ditanggung asuransi kecuali kerusakan akibat kecelakaan yang terdokumentasi. Kerusakan akibat keausan normal tidak ditanggung.
