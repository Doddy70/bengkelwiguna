## 1. Apa Itu Leak Down Test?

### Definition

Leak down test adalah diagnostic untuk mengukur seberapa banyak udara yang bocor dari combustion chamber saat engine diaselupkan dengan tekanan. Diukur dalam persentase (%).

### Prinsip Kerja

```
BAGAIMANA LEAK DOWN TEST KERJA:

1. Spark plug dilepas
2. Piston di-set di TDC (Top Dead Center) - compression stroke
3. Leak down tester (hand pump) dihubungkan
4. Tekanan udara 100 PSI diberikan
5. Persentase kebocoran diukur
6. Lokasi kebocoran diidentifikasi
```

### Apa yang Bisa Dideteksi?

| Kebocoran | Indikasi | Komponen |
|-----------|----------|----------|
| Ke intake manifold | Intake valve bocor | Valve |
| Ke exhaust | Exhaust valve bocor | Valve |
| Ke radiator/coolant | Head gasket bocor | Head Gasket |
| Ke crankcase | Ring/piston rusak | Ring Piston |

## 3. Prosedur Step-by-Step

### Persiapan

```
SEBELUM TEST:
1. Warm up engine ke operating temperature
2. Matikan engine
3. Lepas semua spark plugs
4. Pastikan piston di TDC (compression stroke)
   └─ Carilah tanda timing di flywheel/crankshaft pulley
5. Matikan semua accessories (AC, lights)
```

### BAGIAN 1: Setup

```
LANGKAH 1: Remove Spark Plugs
├── Gunakan spark plug socket
├── Lepas semua 4/6/8 spark plugs
└── 注意: Jangan masuk contaminants ke cylinder

LANGKAH 2: Set Piston Position
├── Putar crankshaft ke TDC compression stroke
├── Cylinder 1: Both valves closed
└── Carilah timing marks

LANGKAH 3: Install Adapter
├── Pilih adapter yang sesuai dengan thread spark plug
├── Pasang ke cylinder head
└─→ Kencangkan dengan tangan dulu
```

### BAGIAN 2: Testing

```
LANGKAH 4: Connect Leak Down Tester
├── Hubungkan tester ke adapter
├── Pastikan seal tight
├── Hubungkan ke air compressor
└── Set regulator ke 100 PSI

LANGKAH 5: Apply Pressure
├── Buka valve di tester
├── Beri tekanan 100 PSI
├── Amati gauge reading
└── Catat percentage kebocoran

LANGKAH 6: Identify Leak Location
├── Dengarkan dengan stethoscope
├── Check intake manifold → intake valve leak
├── Check exhaust → exhaust valve leak
├── Check radiator cap/coolant → head gasket
└── Check crankcase → ring/piston
```

### BAGIAN 3: Dokumentasi

```
SETIAP CYLINDER:
├── Reading percentage: __%
├── Location kebocoran: __
├── Possible cause: __
└── Severity: Normal/Warning/Problem
```

## 4. Interpretasi Hasil

### Persentase Kebocoran

| Persentase | Kondisi | Tindakan |
|-----------|---------|----------|
| **0-5%** | Excellent | Tidak ada masalah |
| **5-10%** | Acceptable | Monitor, belum perlu repair |
| **10-20%** | Warning | Inspection needed |
| **20-30%** | Problem | Repair needed |
| **30%+** | Critical | Immediate repair |

### Lokasi Kebocoran

#### Ke Intake Manifold

```
GEJALA:
- Udara keluar dari intake manifold/throttle body
- Bunyi hisapan dari intake

PENYEBAB:
├── Intake valve tidak menutup sempurna
├── Valve stem aus
├── Carbon buildup di valve

SOLUSI:
├── Valve job
└── Semi Overhaul
```

#### Ke Exhaust

```
GEJALA:
- Udara keluar dari exhaust pipe
- Bunyi dari exhaust

PENYEBAB:
├── Exhaust valve tidak menutup sempurna
├── Valve stem aus
├── Valve seat damage

SOLUSI:
├── Valve job
└── Semi Overhaul
```

#### Ke Radiator/Coolant

```
GEJALA:
- Bubble di coolant reservoir
- Udara keluar dari radiator neck
- Coolant level turun

PENYEBAB:
├── Head gasket bocor
├── Cylinder head crack
├── Block crack (rare)

SOLUSI:
├── Head gasket replacement
└── Overhaul / Semi Overhaul
```

#### Ke Crankcase

```
GEJALA:
- Udara keluar dari oil filler cap
- Crankcase pressure tinggi

PENYEBAB:
├── Ring piston aus/macet
├── Piston ring gap terlalu besar
├── Cylinder wall scoring

SOLUSI:
├── Ring replacement
└── Overhaul Penuh
```

## 5. Perbandingan: Leak Down vs Compression

### Comparison Table

| Aspek | Compression Test | Leak Down Test |
|-------|-----------------|----------------|
| **Mengukur** | Tekanan yang dihasilkan | Udara yang bocor |
| **Unit** | PSI | Persentase (%) |
| **Direction** | Cranking menghasilkan | Pressure applied |
| **Kompleksitas** | Lebih simple | Lebih kompleks |
| **Accuracy** | Good | Excellent |
| **Diagnosis** | General | Specific location |

### Kapan Gunakan Masing-Masing

| Situasi | Test | Notes |
|---------|------|-------|
| Initial check | Compression first | Quick screening |
| Confirmed problem | Leak Down | Pinpoint location |
| Valve suspect | Leak Down | Lebih akurat |
| Ring suspect | Both | Compression + Leak Down |
| Head gasket suspect | Both | Compression + Leak Down |

### Test Combination

```
BEST PRACTICE: GUNAKAN KEDUA TEST

1. Compression Test (Screening)
   └─ Quick check semua cylinder
   └─ Identifikasi cylinder bermasalah

2. Leak Down Test (Deep Dive)
   └─ Konfirmasi masalah
   └─ Identifikasi lokasi kebocoran

COMBINATION:
├── Compression LOW + Leak Down HIGH → Ring/Valve/Head gasket
├── Compression NORMAL + Leak Down HIGH → Valve (early stage)
├── Compression LOW (1 cyl) + Leak Down (intake) → Intake valve
├── Compression LOW (1 cyl) + Leak Down (exhaust) → Exhaust valve
├── Compression LOW + Leak Down (coolant) → Head gasket
└── Compression LOW + Leak Down (crankcase) → Ring/piston
```

## 7. FAQ

### Apa itu leak down test?

Leak down test adalah diagnostic untuk mengukur persentase udara yang bocor dari combustion chamber saat diberi tekanan. Digunakan untuk mengidentifikasi masalah di valve, ring piston, atau head gasket.

### Berapa persentase leak down normal?

Persentase leak down normal adalah **kurang dari 10%**. Di atas 20% indicates masalah yang perlu diperbaiki.

### Apa bedanya leak down test dengan compression test?

Compression test mengukur tekanan yang dihasilkan engine saat di-cranking. Leak down test mengukur berapa banyak udara yang bocor saat tekanan diberikan. Leak down lebih spesifik dalam mengidentifikasi lokasi masalah.

### Apakah bisa melakukan leak down test sendiri?

Bisa, jika Anda memiliki alat dan keahlian. Namun untuk akurasi dan safety, sebaiknya dilakukan oleh teknisi berpengalaman.

### Berapa biaya leak down test?

Biaya leak down test di bengkel berkisar **Rp 100.000 - Rp 300.000** tergantung bengkel. Beberapa bengkel menyertakan免费 sebagai bagian dari diagnostic.

### Leak down 20% apakah perlu overhaul?

Depends pada lokasi kebocoran. Jika di valve = valve job/semi overhaul. Jika di ring = overhaul penuh. Konsultasi dengan teknisi untuk menentukan.

### Bagaimana cara tahu kebocoran di valve?

Dengarkan dengan stethoscope di intake manifold (intake valve) atau exhaust pipe (exhaust valve). Jika terdengar udara bocor di sana, valve bermasalah.

### Head gasket bocor terlihat di leak down test?

Ya, jika ada kebocoran ke coolant/radiator, kemungkinan besar head gasket bocor. Bisa dikonfirmasi dengan compression test juga.
