### 2. Apa Itu Semi Overhaul?

**H2: Apa Itu Semi Overhaul Mesin?**

**Content:**
- Definition: Perbaikan mesin yang fokus pada komponen upper engine (cylinder head area)
- Scope: Bongkar cylinder head, valve train, gasket
- NOT included: Full engine teardown, piston/ring replacement

**Key Points:**
- Lebih ekonomis dari overhaul penuh
- Cocok untuk masalah spesifik
- Waktu lebih singkat

### 6. Proses Semi Overhaul

**H2: Proses Semi Overhaul Step-by-Step**

1. **Persiapan**
   - Parkir di area kerja
   - Drain coolant
   - Disconnect battery

2. **Remove Upper Components**
   - Lepas intake manifold
   - Lepas exhaust manifold
   - Lepas timing cover
   - Dokumentasi timing position

3. **Remove Cylinder Head**
   - Lepas camshaft
   - Lepas valve train
   - Lepas cylinder head

4. **Inspection & Repair**
   - Inspect valve seats (KO-008)
   - Check cylinder head warpage
   - Valve job jika perlu
   - Replace all gaskets

5. **Assembly**
   - Install head gasket baru
   - Set valve train
   - Set timing (belt/chain)
   - Install manifold

6. **Testing**
   - Fill coolant
   - Start engine
   - Check for leaks
   - Road test

**Duration:** 3-5 hari kerja

| **Scope** | Upper engine | Full engine |

| **Cocok untuk** | Valve seal, head gasket | Ring aus, bore macet |
| **Garansi** | 3-6 bulan | 6-12 bulan |

**Decision Guide:**

```
CHOOSE Semi Overhaul IF:
├── [ ] Mesin makan oli ringan-sedang
├── [ ] Overheat ringan tanpa coolant campur oli
├── [ ] Timing belt/chain perlu ganti
├── [ ] Budget terbatas
└── [ ] Teknisi merekomendasikan

CHOOSE Overhaul Penuh IF:
├── [ ] Mesin makan oli parah
├── [ ] Compression loss signifikan
├── [ ] Bore/score pada cylinder
├── [ ] Crankshaft bearing aus
├── [ ] Semua komponen sudah aus
└── [ ] Teknisi merekomendasikan
```
