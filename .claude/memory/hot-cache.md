# Hot Cache (SEO & Content Strategy)

## Kapan Harus Tune Up Mobil
- **Intent:** Informational (Edukasi & Pengecekan Kondisi).
- **True Difficulty:** 75/100 (Hard - Didominasi ATPM raksasa).
- **Strategy:** Target *Long-Tail Localized Keyword* seperti "Tanda mobil harus tune up dan rekomendasi bengkel di Depok".
- **Must-Have Features:** *Bulleted list* untuk memicu *Featured Snippets*, dan *FAQ Schema* untuk memicu *People Also Ask (PAA)*.
